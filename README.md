# Jame Gam Game Jam - 2026

This is a repository containing source code and assets for our entry into the Hack Club Game Jam.

We had lots of fun designing this adventure themed platformer game, we hope you enjoy!!

Download Link: TBC

## Important Note:

Because I created the ALS sets with Ableton Live 12 Suite, there is a possibility that there are Ableton plugins that can't be used on lower versions, such as Lite, Intro or Standard. If this is the case, make a Github Issue and I will give an alternative.

## Tools Used:

- JetBrains Rider
- Ableton Live 12 Suite
- Unity Engine
- Krita
- Clip Studio Paint

## Audio Plugins Used:

- FabFilter Pro Q 4
- FabFilter Pro L 2
- Valhalla Vintage Verb
- Waveform Compressor - Woodstock Audio
- Arturia Pigments Play
